# API RESTful de Gerênciamento de Academia 🏋️‍♀️🏋
## Stacks Utilizadas
- Java 21
- Spring Framework
   - Criação de aplicação web com `Spring MVC` 
- Spring Boot
   - Automatização da configuração inicial do `Spring Framework`
- Spring DATA JPA
   - Acesso aos dados e `persistência` no banco de dados `relacional`
- Spring Security
  - Autenticação e Autorização com `JWT (JSON Web Token)`
- HATEOAS
  - Links de `Hipermídia`
- PostgreSQL
  - `Database`
- Postman
  - Envio de requisições `HTTP` para testes
